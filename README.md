# Salary Tracker

Учебное React + Vite приложение для учёта доходов и расходов.

## Запуск

```bash
npm install
npm run dev
```

После запуска откройте адрес, который покажет Vite в терминале.

## Основные возможности

- доходы и расходы;
- хранение данных в localStorage;
- история операций;
- добавление, редактирование и удаление;
- фильтр по типу и дате;
- баланс;
- аналитика через Recharts;
- маршруты Главная / История / Аналитика.
